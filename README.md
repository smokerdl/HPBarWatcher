# HPBarWatcher

Windows-приложение для наблюдения за полосами HP, энергетического щита (ES) и маны.

## Текущий этап

**Первая рабочая версия.** Программа захватывает выбранную пользователем область, распознаёт HP, энергощит и ману, а при включённых автонажатиях отправляет короткие физические нажатия клавиш по индивидуальным порогам ресурсов. Автонажатия выключены по умолчанию.

## Требования

- Windows 10/11
- Python 3.11 (рекомендуется)
- Git

## Установка и запуск

```powershell
cd C:\Dev\HPBarWatcher
py -3.11 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
pip install -r requirements-dev.txt
python main.py
```

Если PowerShell запрещает активацию окружения, можно запускать напрямую:

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements-dev.txt
.\.venv\Scripts\python.exe main.py
```

## Использование диагностики

1. Нажми **«Выбрать область…»**.
2. Обведи прямоугольником место, где обычно отображается HP-бар. Оставь запас по вертикали, чтобы небольшие перемещения бара оставались внутри области.
3. Убедись, что значение **«Полная ширина полосы»** соответствует игре. По пяти предоставленным образцам начальное значение — 82 пикселя.
4. Нажми **«Начать диагностику»**.
5. Смотри текущие проценты и предпросмотр выбранной области.

В меню, на загрузке и в других местах без HUD статус должен быть «HP-бар не обнаружен», а не 0%.

## Структура

- `app/vision/` — захват экрана и распознавание полос.
- `app/config/` — сохранение настроек.
- `app/ui/` — интерфейс и выбор области.
- `tests/` — автоматические тесты анализатора.

Настройки хранятся в `%LOCALAPPDATA%\HPBarWatcher\settings.json`.

## Ограничения текущей версии

- Область наблюдения задаётся вручную.
- Текущий детектор подтверждает HUD по паре цветных полос HP и Mana; если одна из них полностью опустеет, обнаружение может временно потеряться. Это будет улучшено после проверки на живом экране и калибровки геометрии.
- ES определяется по светло-бирюзовым верхней и нижней линиям поверх HP. Алгоритм основан на пяти предоставленных образцах и требует проверки на реальном захвате игры.
- Длительность импульса нужно проверить на реальном игровом действии.
- Флажок **«Поверх остальных окон»** закрепляет окно поверх игры. Его состояние сохраняется между запусками.

## Автоматические нажатия

В строках HP, ES и Mana нажми кнопку клавиши и затем нажми нужную клавишу. Сохраняется Windows scan code физической клавиши, а не Unicode-символ. Благодаря SendInput с KEYEVENTF_SCANCODE назначение не зависит от текущей раскладки или регистра.

Автонажатия выключены по умолчанию. Общая галочка включает действия, а галочки ресурсов включают отдельные триггеры. Триггер нажимает клавишу только при переходе сверху порога вниз; после достижения порога при восстановлении он снова вооружается. Исчезновение HP-бара сбрасывает состояние, поэтому повторное появление с уже низким ресурсом не вызывает нажатие.

Для Win32 SendInput используется полная ABI-структура INPUT со всеми членами объединения MOUSEINPUT/KEYBDINPUT/HARDWAREINPUT (40 байт в x64, 28 байт в x86). Размер дополнительно проверяется тестом, чтобы избежать ERROR_INVALID_PARAMETER (WinError 87).

Длительность импульса key-down → key-up по умолчанию 50 мс и настраивается в диапазоне 20–500 мс. Начни с 50 мс и проверь в игре; если игра пропускает нажатия, увеличивай постепенно. Приложение пока не проверяет имя процесса игры: оно блокирует отправку только тогда, когда активным окном является сам HPBarWatcher. Поэтому при включённых автонажатиях держи игру на переднем плане и не переключайся в браузер или другие приложения. Игра должна работать с тем же или меньшим уровнем прав, что и HPBarWatcher.

## Сборка EXE (Windows)

Для сборки самостоятельного исполняемого файла на Windows с Python 3.11:

```powershell
cd C:\Dev\HPBarWatcher
.\build.bat
```

Скрипт устанавливает зависимости из `requirements-build.txt`, запускает тесты и собирает приложение через PyInstaller в режиме one-file без консольного окна. Готовый файл находится в `dist\HPBarWatcher.exe`.

Пользовательские настройки не встраиваются в EXE и продолжают храниться отдельно в `%LOCALAPPDATA%\HPBarWatcher\settings.json`.
